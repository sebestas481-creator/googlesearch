# Citace a zdroje

## Zadání a podklady

- [CS50 Web Programming – Project 0: Search](https://cs50.harvard.edu/web/projects/0/search/) – zadání a popis parametrů vyhledávání.
- [Google Search](https://www.google.com/) – cílová adresa běžného vyhledávání.
- [Google Advanced Search](https://www.google.com/advanced_search) – názvy polí rozšířeného vyhledávání.
- [W3C Markup Validation Service](https://validator.w3.org/) – validace HTML.
- [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/) – validace CSS.

## Použitý prompt

- „Navrhněte front-end pro Vyhledávání Google, Vyhledávání obrázků Google a Rozšířené vyhledávání Google“ včetně specifikace projektu CS50 a požadavků na stránku s ukázkami formulářů, odkazy na validátory, citace a portfolio.
- Následný požadavek uživatele: „udělej to přesně podle zadání, ať to můžu jen odevzdat“.

## Poznámky

- Stránky a styly byly vytvořeny s pomocí AI asistenta.
- Vyhledávací formuláře odesílají GET požadavky na veřejné vyhledávání Google; projekt nekopíruje ani nehostuje výsledky vyhledávání.
- Odkaz označený „Portfolio“ vede na GitHub profil vlastníka repozitáře, protože samostatná adresa portfolia nebyla v zadání uvedena.
